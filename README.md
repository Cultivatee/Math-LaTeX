# 📐 Math-LaTeX

> 与数学相关的latex代码，例如数学教学、数学建模

这个仓库都是关于 **latex** 的内容，每一个最小文件夹中都有 `.tex`、`.pdf` 等后缀的文件，可以通过 `texlive` 或者 `VScode` 等打开 `.tex` 后缀的文件编译。

现在（2026年8月）比较主要的文件夹是：**【数学教学、数学建模】** 两个文件夹。

## 📁 文件夹介绍

> 接下来我按照文件夹名称的顺序介绍每一个文件夹的用处。

### 1. latex画图教程 🎨

一个从零基础学会用latex画图的教程。

> **编者的话：latex画图有什么优势？**
>
> 1. 我认为，latex画图与当今AI的发展极为匹配，只需要复制题目或已知条件，经过短时调教AI，AI就会给你一个相当匹配、精美的图像，无需手工。
> 2. latex画图是矢量图，即，放大无穷倍也可以看清的图片，且直接嵌入文档，免去了另外放在figure文件夹再插入、调整的麻烦。
> 3. 画有关数学的图，latex有专门的数学生态，比如椭圆，如果手工用其他画图软件几乎都不能精准画出特定的椭圆，比如 `x^2/16+y^2/9=1`，但是latex只需要 `elipse(16,9)` 就可以画出精准匹配的图片。

### 2. 简历文件夹 📄

一个用latex编写的简历模板，这个是我从网上下载的，我稍微改了一下，变成了**北京师范大学的简历模板**，读者可以把校徽等图片在 `images` 文件夹里面修改变成自己的简历模板。

## 📝 后记

我认为现在掌握 **latex** 是一个很重要的事情：

1. **第一**，现在只要用好AI配合latex，写论文的效率不知道翻多少倍；
2. **第二**，以前AI没发展的时候，latex的学习成本高出天际，各种语法，符号积累不完，报错也是无从下手，但是现在这些配合AI都较为轻松，学习成本大大降低；
3. **第三**，现在所有AI输出给你，你能看到的文字全都是由latex编写的，也就是说，**latex是AI输出的自然格式**，而不是word，word各种手动设置的功能例如段落选项卡等，既不能靠AI设置，手动设置也麻烦。

在AI盛行的时代，与代码有关的工作效率将越来越高，我认为甚至 **excel** 以至于 **SPSS** 这类需要手动操作的软件，或者不纯粹是代码的软件都已经一定程度上成为更低级一类的工具，现在 **python** 完全可以很大程度上实现SPSS的功能了，**python+AI** 的效率在大工程当中尤为突出——For example，给GPT下指令写代码再复制到python中运行一遍的时间，SPSS的数据清洗还没弄完，精力都快用完了，而python+AI只需要简单看一下程序、报错再调试几遍就可以了，差距明显。
